# Tic-Tac-Toe

My first programming project, built in Python as a fun way to explore programming concepts and GUI development. The game features a modern interface built with CustomTkinter and supports both Player vs Player and Player vs Computer modes.

## Features

* 🎮 Player vs Player mode
* 🤖 Player vs Computer mode using the Minimax algorithm
* 🏆 Score tracking across rounds
* 🔄 Replay option
* ✅ Automatic win and draw detection

## Technologies Used

* Python
* Jupyter Notebook
* CustomTkinter

## Running the Project

This project was originally developed and tested in Jupyter Notebook. If running the standalone version, install the required dependencies and execute:

```bash
python main.py
```

## About

This project marks the beginning of my programming journey. While it's a simple game, it gave me hands-on experience with Python, GUI development, game logic, and implementing the Minimax algorithm for an unbeatable AI opponent.
